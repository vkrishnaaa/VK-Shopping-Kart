# 🛒 VK Shopping Kart

**VK Shopping Kart** is a frontend shopping/e-commerce website created using **HTML and CSS**. This was one of my first projects where I focused on turning a basic website idea into a complete, structured shopping interface.

The main goal of this project was to practice building a realistic webpage layout while learning how different HTML elements and CSS properties work together to create a proper user interface.

## ✨ About the Project

The website is designed around an online shopping experience, with different sections and components arranged to give it the feel of an actual e-commerce platform.

While building it, I focused on creating a clean structure for the webpage and experimenting with **layouts, product sections, buttons, navigation, spacing, typography, colours and visual styling**.

Rather than keeping it as a simple collection of HTML elements, I tried to make the website feel like a complete shopping interface.

## 🎨 What I Practiced

Through this project, I got hands-on practice with:

* Structuring webpages using **HTML**
* Styling webpages using **CSS**
* Creating and arranging different website sections
* Designing product-style cards and layouts
* Working with spacing, margins and padding
* Using fonts, colours and borders to improve the UI
* Creating buttons and navigation elements
* Understanding how different CSS properties affect the overall layout
* Improving the visual consistency of a webpage
* Organizing HTML and CSS code into a proper project

## 🧠 What I Learned

This project helped me understand that creating a website isn't just about writing HTML and adding some CSS. The way different sections are structured, spaced and visually connected makes a huge difference to the final result.

It also gave me more confidence in working with CSS layouts and helped me understand how to take an idea and turn it into an actual webpage.

Most importantly, this project became a starting point for experimenting with more frontend projects and gradually improving my design and coding skills.

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**

No frameworks or JavaScript were used — the project was built from scratch using basic frontend technologies.

## 🚀 Purpose

This project was created as part of my journey into **Frontend Development**. I'm currently learning HTML and CSS and building projects like this to improve through practice instead of only learning theory.

This is one of the projects that helped me start getting comfortable with creating complete webpages and gave me the foundation to move on to more creative and challenging designs.
